# CDR correlation

Recommended identifiers:

```text
test_run_id       generated by the test runner
sipp call number  generated by SIPp
sip_call_id       SIP Call-ID
internal_call_id  your Asterisk UUIDv7 CDR identity
```

Do not overload SIP Call-ID with reporting identifiers.

For a database query:

```sql
SELECT *
FROM cdr
WHERE started_at >= ?
  AND started_at < ?
ORDER BY id;
```

Then correlate the SIP trace using Call-ID.

If your CDR has a UUIDv7 internal ID, use it for time-ordered internal identity while preserving the original SIP Call-ID for protocol correlation.
